ATUL KUMAR — 3D PORTFOLIO
==========================

Files
-----
- index.html       Main portfolio page
- style.css        Layout, colors, responsive styles, and CSS animations
- script.js        Menu, scroll reveals, and Three.js 3D background
- assets/atul.jpg  Profile photo supplied for the portfolio

How to run
----------
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Install the "Live Server" extension (if needed).
4. Right-click index.html and choose "Open with Live Server".

You can also open index.html directly in a browser. For the 3D background,
an internet connection is needed because Three.js is loaded from a CDN.

How to customize
----------------
- Change text and section content in index.html.
- Change colors and spacing in :root in style.css.
- Replace assets/atul.jpg with another portrait (keep the same filename).
- Edit or remove the 3D scene in script.js.
